# Учебный проект Git

Небольшой безопасный проект для практики основных команд Git и GitHub.

## Состав проекта

- `config.json` — простая конфигурация;
- `src/hello.ps1` — демонстрационный PowerShell-скрипт;
- `data/tasks.txt` — пример текстовых данных;
- `.env.example` — образец переменных окружения без настоящих секретов.

## Запуск примера

```powershell
.\src\hello.ps1
```
